# Review Evidence

Read the [review contract](review.md), target text, bibliography, source notes,
original passages, and available result records.

Trace consequential claims to original passages or result artifacts. Check
metadata, scope, and limitations. Reconcile numbers, units, sample counts, metric
definitions, uncertainty, and comparisons across prose, tables, and figures.
Check actual procedures against run records; code options alone do not establish
what an earlier experiment used.

Mark inaccessible sources unverified and unsupported claims unsupported. Search
snippets and source notes may be leads rather than sufficient evidence. Return
read-only findings with precise source locations and uninspected artifacts.
Do not replace references or run new analyses unless separately requested.
