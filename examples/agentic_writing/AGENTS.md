# Academic Writing Example Guidance

> This folder is a template for a separate manuscript project. It does not
> describe this guide's repository. Verify and adapt project paths before use.

## Context

Read linked targets explicitly, resolving paths relative to this file:
- [Project context](manuscript/project-context.md) for layout and build tasks.
- [Author style](manuscript/style.md) for writing and style tasks.
- [Review contract](manuscript/workflows/review.md) for manuscript reviews.
- Read the requested section, relevant evidence, and task plan. Report missing files.

## Evidence and Meaning

- Never fabricate citations, passages, procedures, results, measurements, or
  completed experiments. Identify supporting source and result locations.
- Distinguish observations, interpretations, hypotheses, and proposed work.
- Preserve numbers, units, equations, citation keys, labels, negation, causal
  language, scope, and uncertainty during language and style edits.
- Flag missing support with descriptive `% TODO:` comments in LaTeX or HTML TODO
  comments in Markdown. Never insert empty citation commands.
- Ask when scientific decisions cannot be resolved from evidence; continue
  independent work and report unresolved questions.
- Style samples guide expression, not facts. Do not copy their text.

## Review and Revision

- Reviewers are read-only and assess the same recorded draft version.
- Follow the relevant runbook; distinguish demonstrated issues, questions, and
  optional preferences. Report precise locations and evidence actually read.
- Consolidate findings and preserve disagreements before revision. One editor
  applies selected changes within the requested scope.
- Recheck meaning and evidence after scientific and style edits.
- Report checks actually performed and remaining gaps.
- Instructions do not grant additional permissions or external access.

## Figures and Build

- For this paper example, generate figures only when explicitly requested.
  Report missing figures in reviews; preserve placeholders during edits and
  flag missing specifications.
- Preserve manuscript format, bibliography, and label-based reference commands.
- Verify the actual build procedure and inspect logs before proposing cleanup.
  Do not delete generated files as a default troubleshooting remedy.
